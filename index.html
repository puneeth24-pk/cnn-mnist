How it works

Input image

Your drawing becomes a 28×28 grid of numbers (0 = black, 1 = white), just like MNIST training images.

Conv2D (32 filters)

32 small 3×3 filters slide across the image. Each one detects a simple pattern such as an edge or a stroke direction, producing a feature map. ReLU removes negative values.

MaxPooling

Looks at each 2×2 block and keeps only the largest value. The map gets 2× smaller but keeps the strongest signals.

Conv2D (64 filters)

Looks at the pooled maps and combines simple edges into bigger shapes: curves, corners, loops.

MaxPooling

Shrinks again to 5×5 per map, so the network focuses on what is there and less on exactly where.

Flatten

All 64 maps of 5×5 are unrolled into one list of 1600 numbers so dense layers can read them.

Dense 64 and Dense 32

Every neuron connects to every value from the previous layer, weighs them, and decides how strongly to fire. These layers combine shapes into digit-like evidence.

Dense 10 (softmax)

One neuron per digit 0 to 9. Softmax turns the scores into probabilities that add up to 100%. The highest one is the prediction.

Model code

cnn = models.Sequential([
    layers.Conv2D(32, (3,3), activation='relu', input_shape=(28,28,1)),
    layers.MaxPool2D((2,2)),
    layers.Conv2D(64, (3,3), activation='relu'),
    layers.MaxPool2D((2,2)),
    layers.Flatten(),
    layers.Dense(64, activation='relu'),
    layers.Dense(32, activation='relu'),
    layers.Dense(10, activation='softmax')
])
